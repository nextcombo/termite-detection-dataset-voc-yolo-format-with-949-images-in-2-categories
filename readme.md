# Termite Detection Dataset VOC+YOLO format with 949 images in 2 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 949

Number of annotations (number of xml files): 949

Number of annotations (number of txt files): 949

Labeling category count: 2

Label category names (note that the order of categories in the yolo format does not correspond to this, but is based on the labels folder's classes.txt): ["termite", "wings"]

Number of boxes labeled in each category:

Termite frame count = 1879

Wings frame count = 323

Total frame count: 2202

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
